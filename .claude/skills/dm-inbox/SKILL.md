# DM 받은편지함 처리

meta-dm MCP 서버의 도구로 고객 DM을 처리해요.

## 절대 규칙
- **사용자가 초안을 보고 "보내" 라고 승인하기 전에는 `send_draft`를 부르지 않아요.**
- 여러 초안을 한꺼번에 승인받았더라도, 승인받은 초안 ID만 보내요.
- 먼저 연락 온 고객에게만 답장해요. 처음 보는 사람에게 먼저 보내지 않아요.
- 24시간 답장 가능 시간이 지난 대화는 초안을 만들지 말고, 지났다고만 알려줘요.
- 가격·환불·배송일처럼 확실하지 않은 내용은 지어내지 말고 `[확인 필요: ...]`로 표시해요.

## 순서
1. `list_conversations`를 `needs_reply_only: true`로 불러요.
2. 답장할 대화마다 `get_conversation`으로 앞뒤 맥락을 읽어요.
3. 아래 말투 가이드에 맞춰 `create_draft`로 초안을 만들어요.
4. 사용자에게 표로 보여줘요: 플랫폼, 고객 이름, 고객의 마지막 메시지, 초안 내용, 남은 답장 시간, 초안 ID.
5. 사용자가 고치라고 하면 `update_draft`, 빼라고 하면 `discard_draft`를 써요.
6. 승인된 초안만 `send_draft`로 하나씩 보내고 결과를 알려줘요.
7. 드라이런 결과(`dryRun: true`)가 나오면 실제로 안 나갔다고 분명히 말해요.

## 말투 가이드 (사업에 맞게 고쳐 쓰세요)
- 존댓말, 친근하고 짧게.
- 인사 → 답변 → 다음 행동 안내 순서.
- 이모지는 최대 1개.
- 인스타그램은 1000바이트(한글 약 330자) 제한이 있어요.

## 자주 묻는 질문 (예시, 실제 정보로 바꾸세요)
- 배송: 결제 후 1~3 영업일 출고
- 교환·환불: 수령 후 7일 이내
- 영업시간: 평일 10:00~18:00
