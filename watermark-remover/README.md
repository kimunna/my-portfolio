# 워터마크 지우개

사진 속 워터마크나 글자를 지워 주는 웹 앱이에요.
설치 없이 `index.html`을 브라우저로 열면 바로 써요.
사진은 서버로 보내지 않고 내 브라우저 안에서만 처리해요.

## 사용법

1. 이미지를 끌어 놓거나, 클릭해서 고르거나, Ctrl+V로 붙여 넣어요.
2. 브러시로 워터마크 위를 칠해요. "색 선택"을 쓰면 비슷한 색을 한 번에 골라요.
3. "지우기"를 누르면 주변 색으로 자연스럽게 채워 줘요.
4. "이미지 저장"으로 PNG 파일을 받아요.

## 단축키

- `B` 브러시, `E` 빼기, `W` 색 선택
- `[` `]` 브러시 크기 조절
- `Enter` 지우기, `Ctrl+Z` 되돌리기

## 원리

칠한 영역의 바깥 테두리부터 안쪽으로 한 겹씩 주변 색을 섞어 채워요.
그다음 줄무늬를 부드럽게 다듬고, 주변과 비슷한 질감(노이즈)을 살짝 입혀요.
단색이나 그라데이션 배경에서 특히 잘 지워져요.
복잡한 무늬 위의 큰 워터마크는 자국이 남을 수 있어요.

본인이 권리를 가진 이미지에만 사용해 주세요.
