# ☄️ 운석 피하기

떨어지는 운석을 좌우로 피하면서 오래 버티는 간단한 웹 게임입니다.
HTML · CSS · JavaScript 파일만으로 만들어져서, 설치 없이 브라우저로 바로 열어 볼 수 있습니다.
게임의 난이도는 `설정.js` 파일의 숫자만 바꾸면 되도록 분리해 두었고, 브랜치를 바꿔 가며 여러 난이도를 실험해 보는 연습용 프로젝트이기도 합니다.

---

## 📁 폴더와 파일 구조

```
포트폴리오/
├── index.html   ← 화면의 뼈대 (제목, 게임판, 점수판, 버튼)
├── style.css    ← 화면의 디자인 (색, 크기, 배치)
├── 설정.js       ← 게임 난이도 설정 ⭐ 여기만 고치면 됩니다
├── 게임.js       ← 게임 본체 (움직임, 충돌, 점수 계산) — 고치지 않습니다
└── README.md    ← 지금 보고 있는 설명 파일
```

각 파일이 하는 일을 한 줄로 정리하면:

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 브라우저가 제일 먼저 읽는 파일. 나머지 파일들을 불러옵니다. |
| `style.css` | 어떻게 **보일지**를 정합니다. |
| `설정.js` | 게임이 얼마나 **어려울지**를 정합니다. |
| `게임.js` | 게임이 어떻게 **동작할지**를 정합니다. |

> ⚠️ `index.html` 안에서 `설정.js` 가 `게임.js` 보다 **먼저** 불러와집니다.
> 설정값이 먼저 준비돼야 게임이 그 값을 쓸 수 있기 때문에, 이 순서는 바꾸면 안 됩니다.

## ▶️ 실행 방법 (브라우저로 여는 법)

### 🌐 방법 0 — 인터넷에서 바로 플레이 (다운로드 불필요)

GitHub Pages에 올려두었기 때문에, 아래 주소를 누르면 누구나 바로 플레이할 수 있습니다.

👉 **https://kimunna.github.io/my-portfolio/**

> 저장소 주소(`https://github.com/kimunna/my-portfolio`)는 **코드를 보관하는 곳**이고,
> 위 `github.io` 주소는 그 코드가 **실제로 실행되는 곳**입니다. 둘은 서로 다른 주소입니다.
> `main` 브랜치에 `git push` 하면 잠시 뒤 위 주소에도 자동으로 반영됩니다.

---

아래는 내 컴퓨터에 받아둔 파일로 실행하는 방법입니다.
서버를 켤 필요도, 프로그램을 설치할 필요도 없습니다. **`index.html` 파일을 브라우저로 열기만** 하면 됩니다.

**방법 1 — 마우스로 (가장 쉬움)**

1. 탐색기에서 `포트폴리오` 폴더를 엽니다.
2. `index.html` 파일을 **더블클릭**합니다.
3. 기본 브라우저가 열리면서 게임이 나타납니다.
   - 다른 브라우저로 열고 싶다면 파일에 **마우스 오른쪽 클릭 → 연결 프로그램 → Chrome / Edge** 를 고르세요.

**방법 2 — 명령어로**

PowerShell에서 이 폴더로 이동한 뒤:

```powershell
start index.html
```

**게임 조작법**

- `시작` 버튼을 누르면 게임이 시작됩니다.
- `←` `→` 방향키 또는 마우스 이동으로 우주선을 좌우로 움직입니다.
- 운석에 부딪히면 GAME OVER, `스페이스바`를 누르면 다시 시작합니다.
- 피한 운석 수가 점수가 되고, 최고 기록이 오른쪽에 표시됩니다.

**난이도 바꿔 보기**

`설정.js` 를 메모장이나 편집기로 열어 숫자를 바꾸고 저장한 뒤, 브라우저에서 `F5`(새로고침)를 누르면 바로 반영됩니다.

```js
운석_생성간격: 260,   // 숫자를 키우면 운석이 드문드문 → 쉬워짐
운석_낙하속도: 5.0,   // 숫자를 줄이면 천천히 떨어짐 → 쉬워짐
```

## 📝 배운 것

- HTML은 뼈대, CSS는 디자인, JS는 동작 — 역할을 파일별로 나누면 고칠 곳을 바로 찾을 수 있다.
- 자주 바꾸는 값(난이도)을 `설정.js` 로 따로 빼두면, 복잡한 코드를 건드리지 않고도 게임을 바꿀 수 있다.
- `<script>` 태그는 쓰여 있는 순서대로 실행되므로, 먼저 필요한 파일을 위에 둬야 한다.
- `<canvas>` 와 `requestAnimationFrame` 으로 그림을 계속 새로 그리면 움직이는 화면이 된다.
- 두 물체의 중심 거리를 반지름의 합과 비교하면 부딪혔는지 알 수 있다(충돌 판정).
- 컴퓨터마다 프레임 속도가 달라서, 시간 간격(`배속`)을 곱해줘야 속도가 똑같이 느껴진다.
- Git 브랜치를 나누면 원본을 망가뜨릴 걱정 없이 마음껏 실험해 볼 수 있다.
